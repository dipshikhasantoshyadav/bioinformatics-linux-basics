# Bacterial DNA Sequence Analysis Using Python

## Project Overview

This project demonstrates basic DNA sequence analysis using Python. A sample bacterial DNA sequence is analysed to understand its nucleotide composition and calculate fundamental sequence statistics.

## Dataset

- **Input:** Sample bacterial DNA sequence
- **Format:** FASTA
- **File:** `data/sample.fasta`

## Analysis Workflow

1. Load the DNA sequence.
2. Calculate the total sequence length.
3. Count individual nucleotides (A, T, G and C).
4. Calculate nucleotide percentages.
5. Calculate GC content.
6. Generate a sequence statistics report.

## Tools Used

- Python
- Linux/Unix command-line tools
- Git and GitHub

## Repository Structure

- `data/` – Input FASTA sequence.
- `scripts/` – Python analysis script.
- `results/` – Generated sequence statistics.
- `documentation/` – Additional project notes.
