# Bioinformatics and NGS Portfolio

This repository contains independent bioinformatics projects developed to build practical skills in sequence analysis, RNA-seq analysis and biological data interpretation.

## Projects

### Project 1: Bacterial DNA Sequence Analysis
A Python-based project involving DNA sequence statistics, nucleotide composition and GC content calculation.

[Explore Project 1](Project_01_Sequence_Analysis/)

### Project 2: SARS-CoV-2 RNA-seq Analysis
An R-based differential gene expression analysis comparing mock-treated and SARS-CoV-2-infected human bronchial epithelial cells using GEO dataset GSE147507.

[Explore Project 2](Project_02_SARS_CoV2_RNAseq/)
