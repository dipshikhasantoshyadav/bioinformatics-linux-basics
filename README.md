
# Bioinformatics Linux Basics

## Project Overview
This is my first beginner-level bioinformatics project. It focuses on understanding DNA sequence files and performing basic sequence analysis using Python.

## Objectives
- Understand the FASTA file format.
- Calculate DNA sequence length.
- Calculate GC content.
- Learn basic Linux commands.
- Perform simple bioinformatics analysis using Python.

## Tools Used
- Linux/Unix command line (macOS Terminal)
- Python 3
- FASTA format
- Git and GitHub

## Project Structure
- data/: Contains the sample DNA sequence.
- scripts/: Contains the Python analysis script.
- results/: Contains the sequence statistics.
- documentation/: Project documentation.

## Analysis Performed
The Python script calculates:
1. Total DNA sequence length.
2. GC content percentage.

## Results
- Sequence length: 40 nucleotides
- GC content: 47.5%

## Dataset
A short synthetic DNA sequence was used for this beginner exercise. It is not a real bacterial genome or biological sample.

## Learning Outcomes
Through this project, I learned how to:
- Navigate directories using Terminal.
- Create and manage files.
- Read FASTA sequences.
- Write and execute a Python script.
- Calculate basic DNA sequence statistics.
